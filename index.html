About Entropy

Entropy measures how hard a password is to guess — expressed in bits, where each additional bit doubles the number of combinations an attacker must try. Higher bits mean a larger search space.

Theoretical entropy

Based on apparent character space

Calculated by treating every character as if it could be anything from the full character set used — uppercase, lowercase, digits, symbols. A generic brute-force tool makes no assumptions about how your password was built, so it must search the entire character space. This is the upper bound on difficulty.

Effective entropy

Based on actual generation space

Accounts for how the password was actually constructed. A pronounceable password uses consonant-vowel patterns that shrink the real search space — even if the characters look random. A passphrase draws from a known word list. An attacker who knows the generation method works against effective entropy, not theoretical.

Which should I trust?

Theoretical entropy is a useful upper-bound reference — it shows how hard the password would be to crack if the attacker had no knowledge of how it was generated. Effective entropy is the practical, conservative estimate used by this tool, because it reflects the actual space the generator worked from.

When in doubt, trust effective entropy. Strength ratings and minimum-strength thresholds in this tool are always based on effective entropy — the practical, conservative measure.
